# 💈 Barbearia Navalha de Ouro - Landing Page

Landing page comercial moderna e responsiva, desenvolvida para barbearias e estúdios que buscam captação direta de clientes e agendamentos automatizados via WhatsApp.

## 🚀 Tecnologias Utilizadas

- **HTML5 Semântico:** Estrutura focada em acessibilidade e SEO (`<header>`, `<nav>`, `<main>`, `<fieldset>`, `<table>`, `<footer>`).
- **CSS3 Moderno:** Variáveis CSS (Design Tokens), layout responsivo com CSS Grid e Flexbox, abordagem Mobile-First.
- **JavaScript (ES6+):** Validação de inputs no client-side e integração com a API Click-to-Chat do WhatsApp.

## 📱 Recursos Principais

- Layout 100% responsivo para celulares, tablets e desktops.
- Seções de serviços com tabela de preços e diferenciais da barbearia.
- Formulário inteligente de agendamento que gera mensagens formatadas direto no WhatsApp do estabelecimento.
- Tabela de horários de funcionamento acessível.
